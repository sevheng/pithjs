# __APP_NAME__

A site built with [Pith](https://www.npmjs.com/package/pithjs): no build step, no runtime dependencies.

```sh
npm install        # once: Pith's tools and Vite
npm run dev        # → http://localhost:8000
npm run check      # tests, user flows, every page, accessibility, types
npm run see /      # a page as text + a screenshot
npm run new page about -- --nav
```

How to work on it, for people and AI tools: [AGENTS.md](AGENTS.md).
