# Mini demo

An app built with [Mini](../framework/README.md): Home (counter), Todos (store + lists),
Team (data loading from `/api/team`), Contact (a form with server validation) and About (load speed).

```sh
npm run dev       # → http://localhost:8000
npm run check     # tests, user flows, every page, phone layout, types
npm run see /team # a page as text + a screenshot
```

How to work on it, for people and AI tools: [AGENTS.md](AGENTS.md).
